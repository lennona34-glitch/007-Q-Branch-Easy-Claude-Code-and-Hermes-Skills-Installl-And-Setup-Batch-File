Because this external drive ("My Stuff") is formatted NTFS, macOS mounts it
READ-ONLY. That is totally fine — Q-Branch handles it automatically!

FIRST-TIME LAUNCH ON YOUR MACBOOK PRO:
1. Plug the USB drive into your MacBook Pro.
2. Try double-clicking "Launch Agent (Mac).command" in Finder.
   - If macOS says "access privileges" (normal on read-only NTFS drives),
     open Terminal (Cmd + Space -> type Terminal -> Enter) and paste:

     bash "/Volumes/My Stuff/Q-Branch-Portable/Launch Agent (Mac).command"

WHAT HAPPENS AUTOMATICALLY ON FIRST RUN:
- Extracts the pre-bundled Catalina-compatible Node.js 20 runtime (darwin-x64,
  minos=10.15.0) straight off the USB drive into ~/Q-Branch-Mac/runtime/node/.
- Mirrors your API key, active models, Jev MCP engine, and all 45+ Q-Branch
  skills into ~/Q-Branch-Mac/ (fast local SSD storage — leaves NTFS untouched).
- Creates a clickable shortcut right on your Mac Desktop:
    ~/Desktop/Q-Branch Agent.command
  From run #2 onward, just double-click "Q-Branch Agent.command" on your
  Mac Desktop (works with the USB plugged in OR unplugged!).
