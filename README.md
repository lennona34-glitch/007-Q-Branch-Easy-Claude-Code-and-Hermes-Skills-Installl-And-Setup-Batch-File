## 🚀 Quickstart

### 1. Clone the Repository
```bash
git clone https://github.com/lennona34-glitch/007-Q-Branch-Easy-Claude-Code-and-Hermes-Skills-Installl-And-Setup-Batch-File.git
cd 007-Q-Branch-Easy-Claude-Code-and-Hermes-Skills-Installl-And-Setup-Batch-File
```

### 2. Double-Click `Launch Agent.bat`
*(Or run `Launch Agent.bat` from PowerShell / Command Prompt).*

### 3. Run Setup (`[I]`)
Select option **`[I]` First-Time Agent Setup** from the menu. The wizard will:
1. Verify Node.js and Claude Code CLI (installing globally via npm if missing).
2. Verify WSL2 and Hermes Agent.
3. Prompt for your API Key and Gateway URL (e.g. Experiential Labs or OpenRouter).
4. Auto-deploy all **44 bundled skills** into Claude Code (`~/.claude/skills`) and Hermes Agent (`~/.hermes/skills/vault`).
